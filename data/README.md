# Dataset

The project uses synthetic emergency service operational datasets created to simulate fleet management scenarios.

## fleet_vehicles.csv

Contains emergency fleet information:

- Vehicle identifier
- Vehicle type
- Assigned station
- Operational status


## emergency_dispatch.csv

Contains emergency response activity:

- Incident identifier
- Assigned vehicle
- Incident category
- Response duration
- Dispatch timestamp


Dataset Size:

- 35 emergency vehicles
- 500 dispatch records
- 8 operational stations
